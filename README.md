# OS CPU Scheduling Simulator

Interactive Operating Systems Assignment III project built with vanilla HTML, CSS, and JavaScript. Works offline without external libraries.

## Files
- `index.html` — webpage structure and navigation/tabs.
- `style.css` — visual styling and responsive layout.
- `script.js` — process operations, CPU scheduling algorithms, Gantt chart rendering, calculations, and step log.

## Run locally
Open `index.html` in any modern browser. No install or internet connection is required.

## Features
- Add and remove processes with PID, arrival time, and burst time.
- FCFS, non-preemptive SJF, Round Robin, and MLFQ demo simulations.
- Gantt chart, completion time, turnaround time, waiting time, averages, and CPU utilization.
- Operation log and lab learning content (aim, pseudocode, C example, sample I/O, FAQ).
