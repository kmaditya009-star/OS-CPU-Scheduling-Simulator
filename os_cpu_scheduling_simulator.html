Learning / Lab Reference

AIM: To simulate CPU scheduling algorithms (FCFS, SJF, Round Robin and MLFQ), display execution order using a Gantt chart, and calculate completion time (CT), turnaround time (TAT), waiting time (WT), and CPU utilization.

Lab Procedure:

  1. Enter process ID, arrival time, and burst time; click Add Process.
  2. Repeat to add all processes, or click Load Example for sample data.
  3. Select an algorithm. For RR/MLFQ, set the time quantum.
  4. Click Run Simulation and inspect the Gantt chart and results table.
  5. Compare results between algorithms and explain why the metrics differ.

Key formulas: TAT = CT − AT; WT = TAT − BT; CPU Utilization = busy time ÷ total elapsed time × 100%.

FCFS / SJF (non-preemptive):
1. Set current time = 0.
2. While unfinished processes remain:
   a. Find arrived, unfinished processes.
   b. If none, advance time to next arrival (CPU idle).
   c. Select FCFS: earliest arrival (tie: input order),
      or SJF: smallest burst (tie: arrival then input order).
   d. Run selected process to completion.
   e. CT = finish time; TAT = CT - AT; WT = TAT - BT.

ROUND ROBIN:
1. Sort by arrival time; initialize ready queue and time.
2. Add all processes that have arrived to ready queue.
3. If queue empty, jump to next arrival (idle).
4. Dequeue process; run for min(quantum, remaining burst).
5. Add newly arrived processes; if unfinished, enqueue it.
6. Repeat until all complete; calculate CT, TAT, WT.

MLFQ demo (3 levels):
1. New process enters Q0; Q0 quantum = q.
2. If unfinished after Q0, demote to Q1 (quantum = 2q).
3. If unfinished after Q1, demote to Q2 (FCFS to completion).
4. Higher priority queues run before lower queues.
5. Compute metrics from completion times.

This compact C program demonstrates FCFS scheduling and calculates CT, TAT, WT. The browser simulator supports all four algorithms.

#include <stdio.h>

struct Process { int pid, at, bt, ct, tat, wt; };
int main(void) {
    int n, i, time = 0;
    struct Process p[20];
    printf("Number of processes: "); scanf("%d", &n);
    for (i=0; i<n; i++) {
        printf("Enter PID, Arrival, Burst: ");
        scanf("%d %d %d", &p[i].pid, &p[i].at, &p[i].bt);
    }
    /* FCFS: simple sort by arrival time */
    for (i=0; i<n-1; i++) for (int j=i+1; j<n; j++)
        if (p[i].at > p[j].at) {
            struct Process t=p[i]; p[i]=p[j]; p[j]=t;
        }
    for (i=0; i<n; i++) {
        if (time < p[i].at) time=p[i].at; /* idle */
        time += p[i].bt;
        p[i].ct=time;
        p[i].tat=p[i].ct-p[i].at;
        p[i].wt=p[i].tat-p[i].bt;
    }
    printf("PID AT BT CT TAT WT\\n");
    for (i=0; i<n; i++)
        printf("%d %d %d %d %d %d\\n", p[i].pid,p[i].at,
          p[i].bt,p[i].ct,p[i].tat,p[i].wt);
    return 0;
}

What is CPU scheduling?

CPU scheduling chooses a ready process to execute on the processor.

What is Arrival Time (AT)?

The time when a process enters the ready queue/system.

What is Burst Time (BT)?

The CPU time required by a process to finish execution.

Completion Time (CT)?

The clock time when the process finishes execution.

Turnaround Time (TAT)?

Total elapsed time from arrival until completion: CT − AT.

Waiting Time (WT)?

Total time spent waiting in the ready queue: TAT − BT (for these CPU-only simulations).

FCFS vs SJF?

FCFS selects the process that arrived first. SJF selects the shortest burst among currently arrived processes and is non-preemptive here.

Why Round Robin?

It shares CPU time in slices, improving responsiveness for interactive/time-sharing systems. A smaller quantum adds switching overhead conceptually; this simulator does not model that overhead.

What is MLFQ?

Multilevel Feedback Queue uses multiple priority queues and can demote CPU-heavy processes. This demo uses three queues with fixed quanta and no promotion/aging.
